# Framework Design Decisions

The decision log for the modeling & simulation framework specified in
`framework_spec.md`. Each row records a settled decision and — the reason this
file exists — the alternatives that were considered and rejected, with the
reasoning that rejected them. The spec cites these rows as "row N"; row numbers
are stable and never reused.

Each row states its **current** position. Where a decision was later revised,
the superseded position appears among the rejected alternatives, with the
reason it was abandoned. The full chronological evolution of the design lives
in the git history of `framework_design.md`, the original document from which
the spec and this log were derived.
